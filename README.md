# ひとさじノート

料理初心者向けの、端末内で完結するレシピ・調理記録アプリです。

## 起動

`index.html` をブラウザで開くだけでも使えます。ローカルサーバーを使う場合は、このフォルダで次を実行してください。

```powershell
python -m http.server 8080
```

その後、`http://localhost:8080` を開きます。

## データ保存

レシピと画像はブラウザの IndexedDB に保存されます。外部サービスへの送信はありません。同じブラウザ・同じURLで開くとデータが残ります。ブラウザのサイトデータを削除するとレシピも削除されます。
